# Tetris 3D

A 3D Tetris game written in WebGL

<img src="https://github.com/Cyronio/Tetris3D/blob/main/Tetris_Screenshot.png">

## Instructions

You need to run a server to play the game, for example by "python -m http.server".

## Controls

arrow keys or w,a,s,d for moving the tetracubes

y,x,c for rotating the tetracubes

space or enter for letting them fall down

p for pause

+/- for zooming in and out

g for toggling the grid

j/l, i/k, u/o for rotating the camera

v for toggling between perspective and orthographic view

alternative mouse controls for rotating the camera and zooming in and out
